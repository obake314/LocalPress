出典は Labid Journal の入札用語集ほか。読んだのは 2026-08-22。

## 入札日と開札日は別物

**ここが最も間違えやすく、LocalPress のデータ設計に直接効く。**

| | 入札日 | 開札日 |
|---|---|---|
| 意味 | 入札書を提出する日 | 提出された入札書を開封する日 |
| 主な実施者 | 入札参加者 | 発注機関 |
| 参加者がすること | 入札書・必要書類を提出する | 結果確認、必要に応じて立ち合い |
| 注意 | 提出期限を過ぎると原則参加できない | 結果公表日時も確認が要る |

電子入札や小規模案件では同日に設定されることが多いが、書類審査や価格審査を伴う
案件では別日になる。「入札日＝落札者が決まる日」と思い込むのは誤り。

> **LocalPress にとって**
> **事業者が動く期限は「申請締切日／入札書の提出期限」であって「開札日」ではない。**
> 現状、岩手の EPI 由来の案件は一覧に締切が無く**開札日を締切として扱っている**。
> 開札日を締切として表示すると、実際にはもう参加できない案件を
> 「まだ間に合う」と見せることになる。表示ラベルは「開札日」のまま出し、
> 締切として使っていることを混同させない作りにしておく必要がある。
> `src/lib/bidSpec.ts` の `ORDER` と `BidSpecTable` のラベル設計に関わる。

## 入札方式

| 方式 | 内容 | 参加のしやすさ |
|---|---|---|
| 一般競争入札 | 情報を公示して参加を募る。参加資格があれば誰でも参加できる | 最も低い |
| 指名競争入札 | 発注者が指名した者だけで競争する。公募型・簡易公募型・工事希望型などがある | 中 |
| 企画競争入札 | 提示された要件・予算に対し事業者が提案し、内容を審査して契約する。いわゆるコンペ | 中 |
| 公募型プロポーザル | 複数事業者に企画を提案させ、優れた提案者を選定して契約する | 中 |
| 随意契約 | 発注者が任意に決めた相手と契約する。緊急時や新商品購入など一定の条件下でのみ可 | 最も高い |
| オープンカウンタ（公募型見積もり合わせ） | 基準額以下の物品・印刷物などで、公募により参加者を募って契約先を決める。少額随意契約の一種 | 低い |

企画競争入札とプロポーザル方式はどちらも価格以外の提案内容で選ばれる点が共通する。
プロポーザルは「提案者を選ぶ」段階と「契約内容を詰める」段階を分けることがある点で
呼び分けられるが、**呼称は発注機関ごとに運用が違う**ため、公告内容での確認が要る。

## 手続きに関する語

| 語 | 意味 |
|---|---|
| 公示 | 入札の基本情報（参加要件・日時・場所など）を公開する手続き |
| 公示書 | 公示の内容をまとめた書類 |
| 案件公示日 | 案件が公示された日。ここから入札日までに資格確認と見積準備をする |
| 応札 | 競争入札に参加すること。参加者を応札者と呼ぶ |
| 意見招請 | 入札公告に先立ち、仕様書案について企業から意見を求めること |
| 資料招請 | 調達の実際上の必要性について企業から資料提供を求めること |
| 電子入札 | オンラインで入札手続きを行う仕組み。導入状況は発注機関ごとに違う |

## 落札に関する語

| 語 | 意味 |
|---|---|
| 最低制限価格 | 落札の下限価格。下回ると失格。不当な低価格・低品質を防ぐために設定される |
| 不調 | 公告しても入札者がいない、または予定価格を下回る入札が無く、入札を行わないこと |
| 不落随契 | 入札不落の際に行われる随意契約。再度入札しても落札者がないときに実施される |

## WTO案件

WTO「政府調達に関する協定」（GPA）に基づき、**海外企業も参加できる案件**。
対象は国の機関だけでなく、**都道府県や政令指定都市も含む。**

基準額は**原則2年ごとに見直される**ため、同じ自治体・同じ品目でも年度によって
対象範囲が変わりうる。

> **LocalPress にとって**
> 宮城の efftis には `wto_CD`（通常／WTO）という絞り込みがある。
> 収集時に拾えば、事業者にとって意味のある区分として出せる。

## 入札参加資格

- **全省庁統一資格** — 1つの申請で全省庁の一般競争入札・指名競争入札に参加できる共通資格。
  等級は A〜D。有効期間内であれば複数の入札に参加できる
- **自治体個別資格** — 自治体ごとに独自の資格を要求する場合がある
- 資格審査申請は定期的な更新が要る

参加可否を左右する条件には、資格のほかに **売上規模・従業員数・経営状況・営業区域・
営業所の所在地・過去の実績**がある。特に自治体案件では**営業実績や営業所の所在地が
要件になることがある。**

> **LocalPress にとって**
> 「参加できる案件かどうか」は資格と地域で決まる。
> 地域で絞れることは、全国横断のサービスに対する明確な優位点になりうる。
